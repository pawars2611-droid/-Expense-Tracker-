# Expense Tracker

## Description

A simple Python project that helps users record expenses and calculate total expenses.

## Features

- Add Expense
- Show Expenses
- Show Total Expense
- Exit the program

## Technology Used

- Python

## Python Concepts Used

- Variables
- Input and Output
- If-Else
- While Loop
- For Loop
- List
- Dictionary

## How to Run

Run:

python expense_tracker.py
